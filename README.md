# FitLog - Fitness Workout Tracker

**Live Link:** https://fitlog-final.vercel.app/
**GitHub:** https://github.com/bicromroy/fitlog-final

## Project Overview
FitLog is a modern fitness tracking web app where users can browse exercises, create workout plans, and save workouts.

## Features
- 🏋️ Browse exercises with category & details
- 📋 Create custom workout plan (Total: 5 exercises, 91 min, 1092 kcal)
- 💾 Save workouts with LocalStorage
- ⚡ Dynamic routes & loading skeletons
- 📱 Fully responsive (Mobile + Desktop)
- 🎨 DaisyUI + Tailwind CSS

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS + DaisyUI
- React Context API
- LocalStorage for persistence
